# Процесс разметки и проверки

## 1. Подготовка

Зафиксированы 400 основных фотографий и 40 вспомогательных: 10 для обучения, 10 для bbox-экзамена и 20 ханипотов. Для всех фотографий проверены прямые ссылки и лицензии CC0.

## 2. Первичная разметка

Исполнители проекта `11915` выделяли каждую взрослую бабочку отдельной прямоугольной рамкой. Отдельно выбирались ответы "Бабочек нет" и "Ошибка загрузки".

К боевому пулу допускались исполнители с экзаменационным навыком `21750` не ниже 80. В основном пуле использовалось перекрытие 1, поэтому по каждой фотографии собирался один первичный ответ.

## 3. Независимый Review

Ревьюеры проекта `11914` видели полный кадр и предложенные рамки. Они выбирали один из трёх вердиктов:

- принять;
- отправить на исправление;
- направить на ручной разбор.

Каждый ответ проверяли два разных ревьюера. Автор рамок был исключён. К пулу допускались ревьюеры с навыком `21751` не ниже 80.

Решение формировалось так:

- два голоса "Принять" - исходные рамки подтверждены;
- два голоса "На исправление" - ручное исправление;
- разные голоса или "Ручной разбор" - ручное решение команды.

## 4. Ручной разбор

Ручной разбор потребовался для 74 фотографий: 34 отклонённых двумя ревьюерами, 39 с разногласиями и одной фотографии с исходной ошибкой загрузки.

Только 50 фотографий потребовали изменений.

## 5. Golden set

В итоговый набор включены все 400 основных фотографий. Для каждой сохранены рамки либо подтверждённое отсутствие бабочек. Ошибок загрузки в итоговом наборе нет.
