# Материалы проекта

Здесь собраны результаты разметки фотографий бабочек и материалы, по которым можно проследить, как получен итоговый набор.

## Итоговая разметка

- [`golden_set.jsonl`](data/final/golden_set.jsonl): проверенная разметка 400 фотографий с нормализованными координатами рамок. Для каждого снимка сохранены рамки или подтверждённое отсутствие бабочек.

## Методика и отчёты

- [Процесс разметки и проверки](docs/process.md): первичная разметка, независимая проверка, ручной разбор и сборка итогового набора.
- [Сводка по качеству](docs/quality_summary.md): покрытие разметкой, результаты проверки и ручного разбора.
- [Статистика разметки](docs/annotation_statistics.md): причины ручных решений и происхождение итоговой разметки.
- [Расходы на разметку](docs/expenses.md): расчёт затрат с учётом комиссии платформы.

## Промежуточные данные и ручной разбор

- **Исходные API-выгрузки (`data/raw/`)**: обезличенные [ответы разметчиков](data/raw/исходная_разметка_raw.json) и [ответы ревьюеров](data/raw/вердикты_ревью_raw.json).
- **Нормализованные данные (`data/normalized/`)**: [первичная разметка](data/normalized/исходная_разметка.jsonl) и [вердикты с комментариями ревьюеров](data/normalized/вердикты_ревью.jsonl).
- **Ручной разбор (`data/audit/`)**: [журнал решений по 74 фотографиям](data/audit/corrections.jsonl) и [список `photo_id` примеров исправленных ошибок](data/audit/ошибки_примеры.txt).

## Исходные данные

В папке [init/](init/) собраны 400 фотографий iNaturalist с лицензией CC0, список ссылок на оригиналы и описание выборки. Ещё 40 фотографий подготовлены для обучения, экзамена и контроля качества разметки.

## Скрипты

В папке [src/](src/) находятся скрипты для сбора данных, скачивания фотографий Контеста, запуска моделей и оценки предсказаний. Там же приведены инструкции по запуску и список зависимостей.
