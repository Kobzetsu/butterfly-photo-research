# Материалы этапа разметки

- `golden_set.jsonl` - итоговая проверенная разметка 400 фотографий с нормализованными координатами рамок.
- `corrections.jsonl` - журнал ручных решений и исправлений по 74 фотографиям.
- `исходная_разметка.jsonl` - нормализованные ответы исполнителей боевого bbox-пула.
- `исходная_разметка_raw.json` - исходная обезличенная API-выгрузка ответов боевого bbox-пула.
- `вердикты_ревью.jsonl` - нормализованные вердикты и комментарии ревьюеров.
- `вердикты_ревью_raw.json` - исходная обезличенная API-выгрузка ответов боевого Review-пула.
- `process.md` - описание последовательности разметки, независимой проверки и сборки golden set.
- `quality_summary.md` - сводная статистика покрытия, Review и ручного разбора.
- `annotation_statistics.md` - статистика причин ручных решений и происхождения итоговой разметки.
- `expenses.md` - расчёт затрат на разметку с учётом комиссии платформы.
- `bbox_instruction.png` - полноразмерная PNG-версия инструкции для bbox-разметчиков.
- `review_instruction.png` - полноразмерная PNG-версия инструкции для ревьюеров.
- `ошибки_примеры.txt` - список `photo_id` выбранных примеров исправленных ошибок.
